# Network as Code CI/CD

Network automation and CI/CD laboratory.

## Project Goals

- Network as Code
- NetBox as Source of Truth
- Python network automation
- Ansible configuration management
- Batfish network validation
- Git/GitHub version control
- CI/CD pipeline
- GNS3 network environments
- Automated testing
- Network observability

## Planned Environments

- DEV
- TEST
- STAGING
- PROD

## Network Lab

GNS3 will provide the network infrastructure used for testing
automation and CI/CD workflows.

## Architecture

NetBox → Python/Ansible → GNS3

Git → CI/CD → Validation → Deployment
